# Scientific Calculator

A simple scientific calculator made using Python. It can perform basic arithmetic operations as well as various scientific and mathematical calculations.

## Features

- Basic arithmetic operations (`+`, `-`, `*`, `/`, `%`)
- Power operations (`^`)
- Parentheses and operator precedence
- Scientific constants like PI, E, G, h, c, and others
- Trigonometric and hyperbolic functions
- Logarithmic and exponential functions
- Factorial, nCr, nPr, and roots
- Number theory functions like gcd, lcm, totient, and fusc
- Scientific notation support
- Error handling for invalid expressions

## How to Run

Make sure Python is installed on your system.

Run the calculator using:

```bash
python scicalc.py
```

Enter a mathematical expression when prompted.

Type `exit` to close the calculator.

## Example

```text
SciCalc> 2+3*4
14.0

SciCalc> 2^3^2
512.0

SciCalc> sin(PI/2)
1.0

SciCalc> nCr(5,2)
10
```
